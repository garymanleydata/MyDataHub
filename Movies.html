User Guide & Data Tools

1. Historical Bulk Load (Google Apps Script)

Extract all historical ticket confirmation emails from tickets@cineworldtickets.com directly into a Google Drive JSON backup file:

  1. Open Google Apps Script and click New Project.
  2. Click below to download CineworldBulkExporter.gs and paste its code into the editor.
  3. Click Run, authorize read permissions, and download cineworld_history_backup.json from Google Drive.
  4. Click Import Backup File in the header above.
